# 判定口径与评审场景（Day7 · P1 队长）

> 版本：v0.1（2026-10-07，Day7）
> 用途：与 P3 对齐"哪些必须判对、哪些可提示低置信"；定义 2 个端到端演示场景剧本。
> 配套：`RULES.md`（要件）、`CASES.md`（判例）、`eval_v1.json`（评测集）。

---

## 1. 判定口径（P1 ↔ P3 对齐）

### 1.1 分级：哪些必须判对

| 级别 | 场景 | 口径 | confidence 要求 |
|------|------|------|----------------|
| **A 类（必须判对）** | 单车型过错明显：追尾、逆行、倒车、闯红灯、变道未让行、转弯未让行 | 责任结论必须准确（primary/secondary/equal/none），不可含糊 | ≥ 0.7，否则标低置信 |
| **B 类（可提示低置信）** | 双方都有过错（路口各有过失、车-行人需判断行人过错） | 责任倾向 + 理由，可提示"需人工复核" | 0.5–0.7，可 low_confidence |
| **C 类（兜底补录）** | 夜间/遮挡/多车混乱/要素不足 | 不强判，输出 unknown + 转文字补录 | <0.5，**必须** low_confidence |

> 原则：**永不承诺 100%**。拿不准就"低置信 + 提示人工复核"，而不是硬给错误结论。

### 1.2 判定输出要求（对齐 CONTRACTS）
- 责任占比：`primary/secondary/equal/none` + `split`（如 70/30）
- 理由分条 `reasoning`：如 ["A 未让行直行车辆", "B 超速"]
- 法条引用 `basis`：命中 `RULES.md` 对应条款
- 免责 `note`：始终"非最终裁定"

### 1.3 评测断言口径（供 D8 回归）
- A 类：结论必须命中 `eval_v1` 期望 & confidence ≥ min。
- B 类：结论命中 或 low_confidence 兜底均可。
- C 类：必须 low_confidence + unknown，命中即算通过。

## 2. 两个端到端演示场景剧本

### 场景 A：高速追尾（车主视角 · 走"上传→判定→应急"全链路）
- **输入**：车主上传一段"高速后车追尾前车"的行车记录仪视频（清晰）。
- **预期流程**：视频感知 → 追尾要件（后车未保持距离）→ 判定"后车主责 100/0" + 引道交法 43 条 → 应急"追尾模板"（双闪/三角牌/撤离/报警）。
- **演示要点**：突出"上传即有结果 + 处置步骤清晰 + 置信度展示"。
- **期望结论**：`primary / none / 100/0`，confidence ≥ 0.7。

### 场景 B：斑马线撞行人（车主视角 · 最高紧急度 + 降级兜底）
- **输入**：雨天夜间视频，能识别碰撞行人但画面模糊（置信低）。
- **预期流程**：感知置信低 → 系统转"文字补录" → 补录后判定"机动车主责/次责"，应急"撞人模板"（**优先拨 120**，红弹层）。
- **演示要点**：**降级链路兜底**（识别不出也能出结果）+ 最高紧急度提示（120）+ 免责声明。
- **期望结论**：`primary 或 secondary`，必须触发 high 应急 + low_confidence 提示复核。

> 两个场景分别验证：**① 功能全链路闭环（A）② 降级兜底 + 紧急度（B）**，构成有力演示。
