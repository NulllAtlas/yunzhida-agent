# 答辩材料（Day11 · 答辩定稿大纲）

> 版本：v0.1（2026-10-07，Day11 大纲）
> 用途：答辩主材料——背景 / 价值 / 架构 / 演示 / 差异化 / 未来。
> 配套：`DEMO-SCRIPT.md`（三段演示）、`ARCHITECTURE.md`（架构）、`FEASIBILITY.md`（可行）。

---

## 一、背景（为什么做）

- 我国道路交通事故**发生率与二次事故隐患**突出：事故现场第一时间处置不当（未放警示、未撤离、慌乱），常造成更严重后果。
- 责任认定依赖人工判读视频 + 翻查法条，**时效慢、人力成本高**。
- 行车记录仪普及 → 大量视频证据待分析，但缺乏"自动研判"工具。

## 二、价值（解决什么）

**给车主**：事故瞬间给到"该不该拨 120/122、现场先做什么"的即时指引，降低二次事故与处置失当。
**给交警**：把视频自动转为结构化责任依据（占比 + 法条 + 理由 + 证据），提升出认定书效率。
**定位**：**辅助建议**，非最终裁定——输出置信度 + 理由 + 免责声明（合规、可信）。

## 三、架构（怎么做）

- **多智能体编排**（LangGraph）：感知 M1 → 检索 M2 → 判定 M3 → 应急 M4 → 汇聚。
- **降级兜底**：感知置信低 → 转文字/照片补录 → 保证任何输入都出结果（"硬核可选"原则）。
- **技术栈**：Python + FastAPI + LangGraph 后端；Vue3 前端；MoMA 平台接 LLM/视觉模型；chromadb 检索。

## 四、演示（看什么）

1. **车主视角**：上传视频 → 即时应急（红色"立即处置"）+ 责任预判。
2. **交警视角**：责任占比 + 法条 + 理由分条 + 证据清单 → 导出认定书草稿。
3. **降级兜底**：夜间模糊 → 低置信提示 → 文字补录 → 仍出完整结果。
（台词详 `DEMO-SCRIPT.md`；场景详 `CALIBRATION-AND-DEMO.md`）

## 五、差异化（凭什么是我们）

- **闭环优先**："功能不砍、精度递进"，MVP 功能齐全且可演示。
- **降级可靠**：识别不出也能用（全文案/照片兜底），他人往往卡在"识别不准"。
- **合规定位**：明确"辅助建议 + 免责"，契合交警实际使用场景。
- **可落地**：行车记录仪视频为真实高频输入，贴近真实痛点。

## 六、未来（演进方向）

- **迭代 B**：多车轨迹精细重建、夜间/遮挡识别提升、更全法条库、置信评估。
- **规模**：接入交警内网更多案件、裁判文书回流让判定"越用越准"。
- **多端**：小程序/App，事故现场随手可用。
