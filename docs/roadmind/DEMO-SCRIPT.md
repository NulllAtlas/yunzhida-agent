## 演示 ① 视频 → 应急（车主视角）

**画面**：车主端页面，上传短视频 → 进度条 → 结果。

**台词**：
> "行车途中发生事故，车主最慌的是下一秒该做什么。我们把**行车记录仪视频**拖进来，RoadMind 立刻分析。
> 看——系统识别出这是**追尾**，责任偏向后车。更重要的是这条红色提示：**请立即放置三角警示牌、人员撤离**。因为二次事故往往比第一次更致命。

**操作**：
1. 上传视频
2. 展示进度（感知→判定→应急）
3. 强调红色"立即处置" + 应急步骤
4. 展示责任预判 + 置信度 + 免责声明

## 演示 ② 视频 → 责任认定（交警视角）

**画面**：交警端页面，案件列表 → 详情（责任占比/法条/理由）。

**台词**：
> "对交警来说，责任认定是**依据 + 证据**的活。RoadMind 把视频转成结构化分析：这里显示**责任占比 70/30**，理由分条罗列——'A 未让行直行车辆'、'B 超速'，并自动引用**道交法第 47 条**。
> 所有依据、关键帧证据汇总成一张清单，交警只需**复核确认**，就能快速出认定书草稿。"

**操作**：
1. 进案件列表 → 详情
2. 展示责任占比、reasoning、basis（法条）
3. 展示证据清单（关键帧/检测框）
4. 点"导出认定书草稿"

## 演示 ③ 降级场景兜底

**画面**：夜间/模糊视频 → 系统提示"置信度低" → 转文字补录 → 出结果。

**台词**：
> "最考验系统的是**识别不出的时候**。比如夜间模糊视频，检测不到清晰要素——RoadMind 不强猜。
> 它会诚实地说'**置信度偏低**'，并引导车主**文字补录**现场情况：'我车直行，对方左转未让行'。
> 哪怕是纯文字，RoadMind 依然能完成**判定 + 应急**，输出完整结果。这就是'功能不砍、精度递进'的落地：任何输入，都能得到有价值的辅助判断。"

**操作**：
1. 上传夜间/模糊视频（或演示降级提示）
2. 展示"低置信 + 文字补录"入口
3. 补录文字 → 判定 + 应急
4. 点明：低置信 → 提示人工复核（辅助建议定位）
