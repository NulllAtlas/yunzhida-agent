# RESPONSE-TEMPLATE.md · 应急步骤标准模板 v1（Day5 · P1 队长）

> 版本：v0.1（2026-10-04，Day5）
> 用途：给 P3 实现应急智能体（M4）的分步动作标准模板，输出 `response.json`。
> 已核对合规性：三角警示牌距离、报警电话、撤离时机、急救处置。
> 定位：**应急处置建议**，遇到伤亡/起火等请优先拨打 120，勿移动重伤员。

---

## 1. 紧急度分级

| 级别 | priority | 触发条件 | 前端提示 |
|------|----------|---------|---------|
| 最高 | 1 | 人员伤亡、起火、翻车、被困、危险品泄漏、夜间高速 | 红色弹层：立即拨 120/122 |
| 中 | 2 | 一般碰撞、无明确伤亡、车可移动 | 黄色：按步骤处置 |
| 低 | 3 | 轻微刮蹭、无伤亡 | 蓝色：拍照固定证据后协商 |

判定用事故类型画像（追尾/撞行人、起火/翻车等）映射级别。

---

## 2. 报警电话（合规核对）

| 情形 | 电话 | 说明 |
|------|------|------|
| 人员受伤 | **120** 急救 | 说明地点、人数、伤情 |
| 交通事故报警 | **122** | 全国交通事故报警电话 |
| 治安/重大事故 | **110** | 同时可拨打 |
| 保险报案 | 保险公司电话 | 48 小时内 |

> 高速/危险情形优先报警，边报边撤离至安全区。

---

## 3. 三角警示牌距离（合规核对）

| 道路类型 | 放置距离（来车方向） |
|---------|--------------------|
| 城市道路 / 普通公路 | 来车方向 **50 米** |
| 高速公路 | 来车方向 **150 米** 以上 |
| 夜间 / 低能见度 | 在上述基础上适当加大，并开启危险报警灯 |

> 规范依据：《道交法》第 52 条——发生故障或事故后应设置警示标志。

---

## 4. 撤离时机（合规核对）

- **必须立即撤离**：起火、危险品、高速、夜间、来车速度快、无法保证安全。
- **可先固定证据再撤离**：无伤亡、车可移动、普通道路——先打双闪、放三角牌、拍照/录像，再撤离协商，随后快处快赔或报警。
- **切勿**：停留在车道内争执、停留在车后与三角牌之间。

---

## 5. 通用应急步骤（基础模板）

| order | 动作 | urgent | 说明 |
|-------|------|--------|------|
| 1 | 开启危险报警闪光灯（双闪），停车熄火 | 是 | 防二次事故 |
| 2 | 放置三角警示牌（按道路类型定距） | 是 | 见 §3 |
| 3 | 人员撤离至安全地带（护栏外/路肩） | 是 | 高速必撤 |
| 4 | 判断伤亡 → 有则拨 120 | 是/按需 | 最高优先级 |
| 5 | 拨打 122 报警，说明地点/人数/车型 | 按需 | 必要时 110 |
| 6 | 固定证据：拍照/录像全景+细节 | 否 | 车可移动时 |
| 7 | 报保险（48h 内），留存记录仪视频 | 否 | guidance 字段 |

---

## 6. 按事故类型的分场景模板

### 6.1 车-行人 / 撞人（priority 1）
1. 立即开启双闪，停车熄火（urgent）
2. **拨打 120 急救**，说明伤员情况（urgent）
3. 拨打 122/110 报警（urgent）
4. 放置三角警示牌（来车方向，urgent）
5. **保护现场，勿移动伤员**，等待救援（urgent）
- insurance：同步报保险，拍摄现场照片与全景视频，保留证据。

### 6.2 追尾（priority 2）
1. 开启双闪，停车熄火（urgent）
2. 放置三角警示牌（来车方向）（urgent）
3. 人员撤至安全地带，勿留在车道（urgent）
4. 无伤亡可先拍照固定证据后撤离至安全处协商（否）
- insurance：报保险，保留现场照片与行车记录仪。

### 6.3 起火 / 翻车 / 严重（priority 1）
1. 停车熄火，立即撤离人员（urgent）
2. **灭火器初期扑救（仅火势小、安全时）**，否则远离（urgent）
3. 放置三角警示牌 + 拨打 122/110（urgent）
4. 拨打 120（有伤员）（urgent）
5. 勿冒险返回车内取财物（urgent）
- insurance：报保险，保留现场。

### 6.4 一般刮蹭/路口碰撞（priority 2/3）
1. 开启双闪，停车（urgent）
2. 放置三角警示牌（urgent）
3. 拍照固定证据（否）
4. 车可移动则移至安全处；确认责任（否）
5. 拨打 122（责任不明时）/ 报保险（否）
- insurance：留存记录仪视频与现场照片。

## 7. 输出格式（对接 response.json 契约）

```json
{
  "scene_id": "case_xxx",
  "accident_type": "rear_end",
  "priority": 2,
  "steps": [
    { "order": 1, "action": "开启双闪，停车熄火", "urgent": true },
    { "order": 2, "action": "放置三角警示牌（来车方向 50 米）", "urgent": true },
    { "order": 3, "action": "人员撤至安全地带，勿留在车道", "urgent": true },
    { "order": 4, "action": "无伤亡可先拍照固定证据后撤离至安全处协商", "urgent": false }
  ],
  "insurance": "报保险，保留现场照片与行车记录仪。"
}
```

- `emergency_level/priority`：1/2/3 → 对应前端红色/黄色/蓝色提示。
- `steps[].urgent=true`：前端红色高亮"立即"项。
- 字段与 `backend/app/schemas/models.py` 的 `EmergencyResponse/ResponseStep` 一致。
