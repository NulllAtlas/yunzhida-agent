## 🚫 演示禁区（2026-10-06 实测确认，务必避开）

以下几项**当前做不到**，演示脚本 / 评审场景 / 答辩材料里**不要承诺**，否则翻车：

| 不要演示 | 原因 | 系统实际行为 |
|---------|------|-------------|
| **闯红灯判定** | 无法把车辆关联到具体信号灯（同路口红绿灯并存）；电瓶车也识别不出 | `red_light_violation` 输出 `unknown`，如实降级 |
| **非机动车/电瓶车识别** | YOLOv8s(COCO) 无该类别，四组参数零检出，被标成 `car` | 当事方类型会判错 |
| **道路类型/车道/能见度** | 未实现识别 | 恒为 `unknown` |
| **"AI 一眼定责"** | 2D 投影重叠 ≠ 物理碰撞，误报无法根治 | 残留误报需要人工复核 |

**推荐演示素材**：同车道追尾（最常见、要件最明确、判定最稳）、路口两车碰撞。
**务必先用真实事故视频实测一遍再定演示脚本**——手上那段路口视频在修好过检过滤后
是判成"非事故"的（它确实没有事故，22 个"碰撞"全是误报）。

详见 `RULES.md` §3.4 与 §5.1、`ARCHITECTURE.md` §8.1。
