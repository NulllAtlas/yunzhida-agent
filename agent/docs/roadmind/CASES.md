## 2. 入库字段约定（给 P3）

每个案例文件含前置 frontmatter 标签 + 简洁正文，供 RAG 切分。标签建议：
`type`（事故类型）、`keyword`（关键词）、`conclusion`（责任结论，`primary/secondary/equal/none`）。
